## Decision and ownership

Use one fresh unnamed Windows Job Object for each attempt. Configure and query its limits before creating a single worker, and use the process creation job-list attribute to place the worker in that job at birth. Create its initial thread suspended. Retain the process/thread/job handles, verify the expected image, creation identity and singleton membership, then resume once. Refuse before resume if any identity, configuration or membership evidence is absent or inconsistent.

The worker owns later fixture API initialization, admission, acquisition and its local handles. The parent owns only the registered interpreter/worker launch, fixed bounded argument packet, transport, monitoring and termination. Future target member paths are never opened by the parent. There is no retry, alternate executable, alternate worker, post-creation job-assignment fallback or inherited old qualification.

Root alone launches and accepts attempts. Independent source and test/oracle authors own separate new files; every writer holds during every launch. A read-only reviewer checks complete stable artifacts. The independent test author writes complete expected packets, semantic result bodies, output bytes and control predicates from these definitions and authoritative references, never from the new host serializer, reflection, a native self-roundtrip or the result of a previous uncontrolled attempt.

Conservative complete-body accounting is explicit. Let `D <= 4,194,305` be combined retained diagnostic bytes including the one excess sentinel; `B <= 12,582,912` count every full raw buffer occurrence; `H <= 2,097,152` count every other retained hex occurrence; `R <= 1,048,576` be the entire canonical parsed result when present; and `M <= 8,388,608` be every remaining canonical byte. Classify every encoded byte exactly once, while counting repeated copies as separate occurrences. Hex doubles raw length, so the full receipt is bounded by `2D + 2B + 2H + R + M <= 47,185,922` bytes (45 MiB +2), below the proposed64 MiB ceiling. Hex characters need no JSON escaping; their quotes and field wrappers are charged to `M`. The complete own-digest wrapper is also charged to `M`, so the bound applies to the full artifact as well as its hash body.

T2 must independently reconcile the actual schema's allocation/serialization accounting against these categories and equality/first-excess controls. Reserve space for each complete output buffer and every required repeated projection before its API call; use exact requested allocation sizes.
